 Прогнозування цін на квартири з OLX

Проєкт включає повний цикл роботи з даними: від збору оголошень з українського OLX до побудови та порівняння моделей машинного навчання для прогнозування цін на квартири.

---

## Структура проєкту

| Файл | Опис |
|------|------|
| `forest.py` | Кастомна реалізація **Decision Tree Regressor** та **Random Forest Regressor** з нуля (без зовнішніх ML-бібліотек) |
| `parser.py` | Парсер оголошень про продаж квартир з [olx.ua](https://www.olx.ua). Збирає HTML-сторінки та витягує структурований датасет |
| `main.py` | Завантаження даних, розбиття на train/test, навчання кастомного та sklearn Random Forest, порівняння метрик |
| `apartments_dataset.csv` | Вихідний CSV-файл із 9 ознаками (результат роботи парсера) |
| `saved_apartments/` | Папка зі збереженими HTML-сторінками оголошень (створюється парсером) |

## Використання

### 1. Збір даних (опціонально)

Якщо у вас ще немає `apartments_dataset.csv`, запустіть парсер:

```bash
python olx_parser.py
```

**Що робить скрипт:**
1. Обходить сторінки каталогу продажу квартир на OLX.
2. Завантажує HTML кожного оголошення в папку `saved_apartments/`.
3. Парсить HTML і формує CSV із 9 ознаками.

> **Важливо:** скрипт використовує затримки між запитами (1.5–2 с) для ввічливого скрейпінгу.

### 2. Навчання моделей

```bash
python main.py
```

**Що робить скрипт:**
1. Завантажує `apartments_dataset.csv`.
2. Розбиває дані на навчальну та тестову вибірки (80/20).
3. Навчає **кастомний** Random Forest (`forest.py`).
4. Навчає **sklearn** Random Forest для порівняння.
5. Виводить метрики: MAE, RMSE, R².
6. Показує приклади передбачень та важливість ознак.

## Ознаки датасету

| Ознака | Тип | Опис |
|---------|-----|----------|
| `price` | int | **Цільова змінна** — ціна квартири в гривнях |
| `seller_type` | категорія | 0 = Бізнес, 1 = Приватна особа |
| `object_type` | категорія | 0 = Новобудова, 1 = Вторинний ринок |
| `total_area` | float | Загальна площа (м²) |
| `kitchen_area` | float | Площа кухні (м²) |
| `rooms` | int | Кількість кімнат |
| `layout` | категорія | 0 = Студія, 1 = Роздільна, 2 = Смарт-квартира, 3 = Вільне планування, 4 = Пентхаус |
| `furnished` | категорія | 0 = Ні, 1 = Так |
| `renovation` | категорія | 0 = Євроремонт, 1 = Косметичний, 2 = Після будівельників, 3 = Житловий стан, 4 = Авторський проєкт |

## Кастомна реалізація Random Forest

Файл `forest.py` містить повну реалізацію з нуля:

- **MSE** — функція середньоквадратичної помилки (критерій розбиття).
- **NodeReg** — клас вузла дерева (листок / внутрішній).
- **DecisionTreeRegressor** — дерево рішень для регресії з рекурсивним побудовою, пошуком оптимального розбиття за зваженою MSE та обмеженнями за глибиною й мінімальною кількістю зразків.
- **CustomRandomForest** — ансамбль дерев із бутстрап-вибіркою (`bootstrap=True`) та випадковою підмножиною ознак (`max_features='sqrt'`).

Передбачення ансамблю — **середнє арифметичне** передбачень усіх дерев.

---

## Порівняння з sklearn

`main.py` навчає обидві моделі з **ідентичними гіперпараметрами**:

- `n_estimators = 100`
- `max_depth = 15`
- `min_samples_split = 3`
- `max_features = 'sqrt'`
- `bootstrap = True`
- `random_state = 42`

Після навчання виводиться таблиця порівняння за метриками **MAE**, **RMSE** та **R²**, а також приклади передбачень на перших 5 об'єктах тестової вибірки.
