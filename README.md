# Предсказание цен на квартиры с OLX

Проект включает полный цикл работы с данными: от сбора объявлений с украинского OLX до построения и сравнения моделей машинного обучения для предсказания цен на квартиры.

---

## Структура проекта

| Файл | Описание |
|------|----------|
| `forest.py` | Кастомная реализация **Decision Tree Regressor** и **Random Forest Regressor** с нуля (без внешних ML-библиотек) |
| `parser.py` | Парсер объявлений о продаже квартир с [olx.ua](https://www.olx.ua). Собирает HTML-страницы и извлекает структурированный датасет |
| `main.py` | Загрузка данных, разбиение на train/test, обучение кастомного и sklearn Random Forest, сравнение метрик |
| `apartments_dataset.csv` | Выходной CSV-файл с 9 признаками (результат работы парсера) |
| `saved_apartments/` | Папка с сохранёнными HTML-страницами объявлений (создаётся парсером) |

## Использование

### 1. Сбор данных (опционально)

Если у вас ещё нет `apartments_dataset.csv`, запустите парсер:

```bash
python olx_parser.py
```

**Что делает скрипт:**
1. Обходит страницы каталога продажи квартир на OLX.
2. Скачивает HTML каждого объявления в папку `saved_apartments/`.
3. Парсит HTML и формирует CSV с 9 признаками.

> **Важно:** скрипт использует задержки между запросами (1.5–2 с) для вежливого скрейпинга.

### 2. Обучение моделей

```bash
python main.py
```

**Что делает скрипт:**
1. Загружает `apartments_dataset.csv`.
2. Разбивает данные на обучающую и тестовую выборки (80/20).
3. Обучает **кастомный** Random Forest (`forest.py`).
4. Обучает **sklearn** Random Forest для сравнения.
5. Выводит метрики: MAE, RMSE, R².
6. Показывает примеры предсказаний и важность признаков.

## Признаки датасета

| Признак | Тип | Описание |
|---------|-----|----------|
| `price` | int | **Целевая переменная** — цена квартиры в гривнах |
| `seller_type` | категория | 0 = Бізнес, 1 = Приватна особа |
| `object_type` | категория | 0 = Новобудова, 1 = Вторинний ринок |
| `total_area` | float | Загальна площа (м²) |
| `kitchen_area` | float | Площа кухні (м²) |
| `rooms` | int | Кількість кімнат |
| `layout` | категория | 0 = Студія, 1 = Роздільна, 2 = Смарт-квартира, 3 = Вільне планування, 4 = Пентхаус |
| `furnished` | категория | 0 = Ні, 1 = Так |
| `renovation` | категория | 0 = Євроремонт, 1 = Косметичний, 2 = Після будівельників, 3 = Житловий стан, 4 = Авторський проект |

## Кастомная реализация Random Forest

Файл `forest.py` содержит полную реализацию с нуля:

- **MSE** — функция среднеквадратичной ошибки (критерий разбиения).
- **NodeReg** — класс узла дерева (лист / внутренний).
- **DecisionTreeRegressor** — дерево решений для регрессии с рекурсивным построением, поиском оптимального разбиения по взвешенной MSE и ограничениями по глубине и минимальному числу образцов.
- **CustomRandomForest** — ансамбль деревьев с бутстрап-выборкой (`bootstrap=True`) и случайным подмножеством признаков (`max_features='sqrt'`).

Предсказание ансамбля — **среднее арифметическое** предсказаний всех деревьев.

---

## Сравнение с sklearn

`main.py` обучает обе модели с **идентичными гиперпараметрами**:

- `n_estimators = 100`
- `max_depth = 15`
- `min_samples_split = 3`
- `max_features = 'sqrt'`
- `bootstrap = True`
- `random_state = 42`

После обучения выводится таблица сравнения по метрикам **MAE**, **RMSE** и **R²**, а также примеры предсказаний на первых 5 объектах тестовой выборки.

## Примечания

- Парсер ориентирован на **украинскую версию** OLX (`olx.ua/uk/...`).
- Если структура сайта изменится, селекторы в `parse_apartment_html()` потребуют обновления.
- Кастомный Random Forest реализован в **учебных целях** и может быть медленнее sklearn на больших датасетах.
